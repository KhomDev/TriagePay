      How it works

      The key can only ask. The wallet decides.

      1. Pay-only key. The agent account's key can call pay on one wallet. It cannot attach the deposit an owner method needs.
      2. The contract checks. Pause, the agent is active, the token, the allowlist, the per-call cap, the daily cap. A new payee or an amount above the threshold can be held for the owner.
      3. The refusal is a transaction. ERR_PAYEE_NOT_ALLOWED changes no balance. The explorer link is the proof.

      Payee risk

      An allowlisted payee shows warn when the account is under 7 days old, or when its age could not be read. The demo payee was created for this page, so warn is expected. Warn does not move money.
